> Иконки категорий: `ICONS.c_<category>` в `app.js` (SVG, не эмодзи). Карточки «Where to save» — `.adv` с `--c`.
> Навигация назад: реальная история браузера (`goBack`), fallback — `parentHash`.

## Бриф
- Кто: молодой работающий человек в Китае, телефон, проверка 5–10 раз в день по 10 секунд.
- Задача экрана №1: за секунду ответить «сколько могу потратить сегодня до зарплаты».
- Тон: живой, дружелюбный, чуть игровой (есть цели и соревнования), но деньги подаём спокойно и точно. Без стыжения за траты.
- Темы: светлая и тёмная, обе первоклассные. Языки: zh (основной) / en.

```css

@media (prefers-color-scheme:dark){:root:not([data-theme=light]){--paper:#0E1226;--surface:#181D38;--ink:#F2F1FA;--tangerine:#FF8147;--pistachio:#A7E66B;--lilac:#A99CFF;--coral:#FF6B70}}
:root[data-theme=dark]{--paper:#0E1226;--surface:#181D38;--ink:#F2F1FA;--tangerine:#FF8147;--pistachio:#A7E66B;--lilac:#A99CFF;--coral:#FF6B70}
```
Правила: текст на Tangerine — Ink (не белый); Pistachio и Coral не единственный признак (рядом знак +/− или иконка); контраст текста ≥ 4.5:1.

Типографика (одна идея, два семейства):
- Display и числа: Bricolage Grotesque (живой характер), tabular-nums для сумм (проверить поддержку; иначе `font-variant-numeric` + запасной шрифт).
- Текст и китайский: Noto Sans SC. Стек: "Bricolage Grotesque", "Noto Sans SC", system-ui.
- Шкала: 12 / 14 / 16 / 20 / 28 / 44 (hero-число). Строки < 60 зн. на мобильном. Sentence case, без КАПСА-эйбровов.

Форма: радиусы по иерархии, не один на всё: кнопки/чипы — pill (999), панели — 20, мелкие поля — 12. Тень почти не используем; разделяем фоном и отступом. Иконки — Lucide SVG, без эмодзи.

## Раскладка (мобильный 390px — основной)
Memorable-элемент (единственный «громкий»): **полоса дней до зарплаты** — каждый день цикла это сегмент; прошлые окрашены по факту (уложился = Pistachio, превысил = Coral), сегодня = Tangerine и крупнее, будущие — контур. Это реальная последовательность, нумерация оправдана.

Остальное: Chat (ответы бота короткие; тихая запись = маленькая «монетка» в ленте), Import (перетащить файл → превью строк → «проверить»), Goal (кольцо + темп + 2–3 совета), Leaderboard Beta (список по % накопления, моя строка закреплена).
Выравнивание: всё по левому краю; числа и суммы справа в списках.

## Принципы
1. Одно громкое место (полоса дней), остальное тихо.
2. Деньги — всегда точные числа из кода; ИИ только пояснение.
3. Движение только в ответ на действие (запись транзакции → монетка падает; подтверждение → галочка). Без fade-in на каждой секции.
4. Состояния обязательны: loading / empty / error; ошибки без извинений, с «что делать».
5. Текст интерфейса: активные глаголы, одно имя действия на весь флоу («Сохранить» → «Сохранено»).
6. Соревнования: показываем %, не суммы; без штрафов за обязательные траты.
7. Доступность: фокус виден, prefers-reduced-motion, hit-area ≥ 44px, цвет не единственный признак.

## Ревью плана против дефолтов (что изменено)
- Был trust-blue + green на тёмном → заменено на Tangerine/Lilac/Pistachio (не банковский шаблон).
- Был hero «большое число + градиент» → число остаётся, но привязано к полосе дней (несёт информацию).
- Одинаковые карточки с тенью → разные радиусы и отсутствие теней.
- Рукописный шрифт из поиска → отклонён (плохо для чисел и китайского).
