# PRODUCT.md — контекст продукта (для питча и решений)

## Суть
**Проблема:** учёт трат бросают, потому что он утомляет и не даёт пользы в момент ввода. Гипотеза (не доказано): чем меньше действий, тем регулярнее учёт.
**Для кого:** молодые работающие люди в Китае с ежемесячной зарплатой, платят через Alipay/WeChat, не хотят вести таблицы.
**Что делаем:** AI-копилот. Вход: выписка (CSV) или чат (текст/скриншот). Бот запоминает привычки, молча записывает знакомое, спрашивает только неясное/важное, отвечает «сколько можно тратить в день до зарплаты», ведёт к цели и подсказывает, где сократить траты.
**Хакатон:** FinTechathon 2026 (Шэньчжэнь, WeBank), International Track, Topic A — Personal Finance Assistant.

## Отличия (гипотезы, ещё не проверены на людях)
1. Персональная память (продавец, сумма, правки пользователя).
2. Минимум прерываний: молча / в сводку / вопрос сразу; порог по личной истории.
3. Контекст переводов (друг, свои счета, долг) в простой форме.
4. Ответ-действие вместо графика: «¥X в день».
5. Вовлечённость: цель X, соревнования по % накопления (Beta).
6. Learn/Insights (Beta): образование и нейтральные советы, без «купи X».

## Конкуренты (в питче не говорить «мы первые»)
Qianji (6M+, AI, импорт Alipay/WeChat), SuiShouJi (голос, чеки), Cleo, Rocket Money, Monarch.

## Данные
- MVP: выписка CSV (один формат) + чат + скриншот. Автосбор через банки: **Beta/roadmap**; формулировка для питча: «ввод сведён к одному действию, автосбор подключим с банками-партнёрами».
- У Alipay/WeChat нет открытого API к личной истории; скрапинг запрещён и рискован. Plaid не покрывает Китай/Кыргызстан.
- Приватность: PIPL относит финансовые данные к чувствительным → минимум данных, явное согласие, удаление данных, не просим пароли, демо только на синтетике.

## Риски
- Сильные локальные конкуренты → отличие должно быть видно за 2 минуты демо.
- Ввод остаётся полуручным без банковских API → честно маркировать Beta.
- Отличие не подтверждено → замерить метрики (см. SPEC §10), 3–5 коротких интервью.
- Доверие: ошибка молчаливой записи → кнопка «почему так» и отмена в один тап.
- Регуляция: инвестиционные советы в Китае могут лицензироваться → только образование + дисклеймер.
- Соревнования могут поощрять экстремальную экономию → только %, добровольно, без штрафов за обязательные траты.

## Вне MVP (roadmap)
Полноценный инвестмодуль, новостной портал, банковские интеграции, White-Label для банков (B2B), SME-версия (Topic E), реальные пользовательские данные.

## Порядок развития
Учёт → бюджет до зарплаты → цель + советы → (Beta) Learn и соревнования → автосбор через банки → инвестиции/обучение → White-Label.
